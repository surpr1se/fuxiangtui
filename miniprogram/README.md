# 福享退 - 微信小程序

福建省养老保险待遇智能测算平台微信小程序

## 项目介绍

福享退是一款面向福建省企业职工的养老保险待遇测算工具，通过上传社保缴费明细PDF，自动解析并精准测算养老金待遇。

## 功能特点

- 📄 **PDF自动解析**：支持上传福建社保缴费明细PDF，自动解析缴费数据
- 🔢 **精准测算**：基于福建省养老保险政策，精准计算养老金待遇
- 📊 **多方案对比**：支持不同缴费基数方案的对比分析
- 📋 **历史记录**：保存测算历史，方便随时查看
- 📍 **办理指南**：福建省各地市退休办理流程及办事机构信息

## 技术栈

- 微信小程序原生开发
- 微信小程序组件化开发
- 本地存储（Storage）
- 微信登录授权

## 开发环境搭建

### 环境要求

- 微信开发者工具（最新版）
- 微信小程序开发者账号

### 开发步骤

1. **下载微信开发者工具**
   - 访问 https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html
   - 下载并安装对应版本

2. **导入项目**
   - 打开微信开发者工具
   - 选择"导入项目"
   - 选择 `miniprogram` 目录
   - 输入 AppID（测试可使用测试号）
   - 项目名称：福享退

3. **开始开发**
   - 项目导入后即可在开发者工具中预览和调试

## 配置说明

### 后端API配置

在 `utils/request.js` 中配置后端API地址：

```javascript
const baseUrl = 'https://api.fuxiangtui.com'  // 生产环境
// const baseUrl = 'http://localhost:8080'     // 开发环境
```

### 参数配置

可在 `app.js` 中配置以下参数：

- 社平工资
- 个人账户记账利率
- 缴费比例
- 其他政策参数

## 部署说明

### 微信小程序发布

1. 在微信开发者工具中点击"上传"
2. 填写版本号和项目备注
3. 登录微信公众平台 https://mp.weixin.qq.com/
4. 进入"版本管理"，提交审核
5. 审核通过后发布上线

### 后端部署

后端项目请参考后端项目文档进行部署。

## 注意事项

1. **PDF解析**：PDF解析依赖后端服务，部署前请确保后端API正常
2. **数据安全**：用户敏感信息需加密存储和传输
3. **政策更新**：养老保险政策如有变动，需及时更新计算公式
4. **测试环境**：建议在测试环境充分验证后再发布生产
