### 模块1：用户信息区

#### 2.1.1 展示内容

| 元素 | 展示规则 | 说明 |
|------|---------|------|
| **微信头像** | 圆形头像，尺寸 120rpx × 120rpx | 授权成功后自动展示微信头像 |
| **微信昵称** | 字体大小 32rpx，字重 500，颜色 #323233 | 授权成功后自动展示微信昵称 |
| **未授权状态** | 头像显示默认图标，昵称显示"点击授权登录" | 点击触发微信授权 |

#### 2.1.2 授权逻辑

```
用户进入页面
    │
    ▼
检查是否已授权
    ├── 已授权 → 直接展示头像+昵称
    │
    └── 未授权 → 显示默认头像 + "点击授权登录"
        │
        ▼
用户点击授权区域
        │
        ▼
调起微信授权弹窗
        │
        ├── 用户允许 → 获取头像昵称，更新展示
        │
        └── 用户拒绝 → 保持未授权状态
```

#### 2.1.3 UI设计细节

- **背景色**：渐变背景色 #1989fa（与主题色一致）
- **文字颜色**：白色
- **头像边框**：白色边框 4rpx solid rgba(255,255,255,0.3)
- **内边距**：上下 48rpx，左右 32rpx
- **对齐方式**：头像居左，昵称在头像右侧垂直居中
- **间距**：头像与昵称间距 24rpx

## 4. 交互逻辑说明

### 4.1 微信授权登录流程

```
1. 用户进入"我的"页面
2. 检查本地是否有用户信息
   ├─ 有 → 直接展示头像+昵称
   └─ 无 → 显示默认头像 + "点击授权登录"
3. 用户点击授权区域
4. 调用 wx.getUserProfile 获取用户信息
5. 用户允许授权
   ├─ 获取头像URL和昵称
   ├─ 保存到本地存储
   └─ 更新页面展示
6. 用户拒绝授权
   └─ 保持未授权状态，下次进入仍可点击授权
```
