# 福享退 - 养老待遇核定需求分析

## 一、项目整体功能

福享退是福建省退休待遇测算微信小程序，支持**机关保**和**企业保**参保人员退休待遇测算与核定，包含两大功能模块：

1. **参保人自助测算**（面向公众）：
   - 用户输入身份证号码（社会保障号）
   - 系统自动获取出生日期、性别、历年缴费明细
   - 自动预测**退休时间**，计算**距离退休还有多久**
   - 根据参保类型（机关保/企业保）计算预测退休后的养老待遇标准
   - 让参保人提前了解自己能拿多少养老金

2. **养老待遇核定**（面向社保经办机构，本需求文档）：
   - 改革后（2014年10月1日起）在职参保人员获批退休后，满足待遇申领计算条件时，在此核定应领取的退休待遇
   - 生成《基本养老保险参保人员基本养老金计发表》
   - 支持机关事业养老保险和企业养老保险

## 二、V1版本功能 - PDF缴费明细解析与企业养老待遇自助测算

### 1. 功能概述

**版本定位**：第一版应用，仅上线**企业养老待遇测试功能**

**核心流程**：
1. 用户从其他应用下载缴费明细PDF文件
2. 上传PDF文件到福享退小程序
3. 系统自动解析PDF，提取历年缴费明细
4. 展示解析结果供用户核对确认
5. 用户点击计算按钮，系统计算退休待遇

### 3. PDF文件格式说明

**PDF来源**：福建省社保网厅导出的「基本养老个人历年缴费明细」

**PDF类型**：纯文本格式（非扫描图片），无需OCR识别

**文件结构**：

| 区域 | 内容说明 |
|------|---------|
| **文件头** | 标题、社会保障号（身份证号）、姓名 |
| **表格主体** | 历年缴费明细表格，每页约10-11条记录 |
| **页脚** | 打印日期、社保机构、明细编码、温馨提示 |

**表格字段定义**：

| 字段名 | 数据类型 | 示例值 | 说明 |
|--------|----------|--------|------|
| 序号 | 整数 | 1, 2, 3... | 行号，每页重置 |
| 个人编号 | 字符串 | 000961315 | 个人社保编号 |
| 单位编号 | 字符串 | 10120061354 | 参保单位编号 |
| 单位名称 | 字符串 | 福建建友资产评估土地房地产估价有限责任公司 | 跨行显示，需智能合并 |
| 建账年份 | YYYYMM | 202603 | 建账年月 |
| 费款所属期 | 字符串 | 202603至202603 | 缴费年月范围 |
| 缴费月数 | 整数 | 1 | 当月缴费月数 |
| **缴费基数** | 数值 | 4043 | 月缴费基数（核心算法字段） |
| 缴费性质 | 字符串 | 正常应缴 | 缴费类型 |

**PDF解析技术要点**：
1. ✅ 纯文本格式，使用标准PDF解析库即可提取
2. ⚠️ 单位名称跨行显示，需智能合并相邻行
3. ⚠️ 多页PDF每页重复表头，需识别并跳过重复表头
4. ⚠️ 缴费记录按时间倒序排列（从新到旧），解析后可正序重排

**推荐技术方案**：
- Java后端：Apache PDFBox
- Python后端：pdfplumber / PyPDF2

## 四、企业职工基本养老保险 - 退休待遇计算规则

### 1. 企业职工退休年龄规定

| 退休类型 | 男性 | 女性 | 说明 |
|----------|------|------|------|
| **正常退休** | 年满60周岁 | 女工人年满50周岁，女干部年满55周岁 | 女职工的退休年龄按其退休前的岗位确定 |
| **特殊工种** | 年满55周岁 | 年满45周岁 | 高空/特繁累计满10年，井下/高温累计满9年，有毒有害累计满8年 |
| **因病退休** | 年满50周岁 | 年满45周岁 | 经县级以上劳动鉴定委员会鉴定为完全丧失劳动能力 |

> 女职工岗位转换规则：女干部退休前在工人岗位上连续工作满5年的，按年满50周岁退休；女工人退休前在管理岗位上连续工作满5年的，按年满55周岁退休。

---

### 2. 缴费年限认定

**领取条件**：累计缴费年限 **满15年（180个月）**

```
累计缴费年限 = 建账前的缴费年限 + 建账后的缴费年限
```

| 项目 | 说明 |
|------|------|
| **建账前的缴费年限** | 建立个人账户前的实际缴费年限 + 视同缴费年限 |
| **视同缴费年限** | 实行企业和职工个人共同缴纳养老保险费制度之前，按国家规定计算为连续工龄的年限 |
| **建账后的缴费年限** | 建立个人账户开始及之后的实际缴费年限 |

**年限折算规则**：
- 缴费年限累计月数的尾数为 **1-6个月** 的按 **0.5年** 计算
- **7-11个月** 按 **1年** 计算

---

### 3. 退休缴费指数计算办法

#### 3.1 各年度平均缴费指数

**年度期间**：从 **1991年** 至本人退休当年度

| 时间段 | 计算规则 |
|--------|----------|
| 1990年底前 | 每年度的平均缴费指数统一按照 **1** 计算 |
| 1991年 - 2019年退休 | 当年度月平均缴费基数 ÷ 当年度的月社平工资 |
| **2020年度后退休** | **斜比方法**：当年度月平均缴费基数 ÷ **上年度**的月缴费基数上下限 |

**退役军人补缴特殊规则**：
- 缴费指数统一按照 **0.6** 计算
- 与正常缴费部分进行 **加权平均**，最终得出当年度的平均缴费指数

#### 3.2 建账前的平均缴费指数

```
建账前平均缴费指数 = (1990年前缴费指数总和 + 1991年至建立个人账户年月前缴费指数总和) ÷ 建账前的累计缴费月数
```

**保底规则**：
- 退休属性为"国有农场"或"华侨农场"：低于 **0.375** 按 0.375 计算
- 其他人员：低于 **0.75** 按 0.75 计算
- 高于保底值的，按实际建账前的平均缴费指数计算

#### 3.3 实际缴费指数（平均缴费指数）

```
平均缴费指数 T = (建账后的缴费指数总和 + 建账前的平均缴费指数 × 建账前的累计缴费月数) ÷ 累计缴费月数
```

---

### 4. 本人指数化月平均缴费工资

```
本人指数化月平均缴费工资 = 参保人员退休时本省上一年度在岗职工月平均工资 W × 本人平均缴费指数 T
```

> ⚠️ 注意：此处使用的是"退休时本省上一年度在岗职工月平均工资"，与缴费指数计算中的"缴费基数上下限"是不同参数，请勿混淆。

---

### 5. 退休时个人账户储存额

**计息方式**：退休时计息方式为年基数法，针对人群设定对应的年度银行利率。

> 行业单位1999年前银行利率按照行业的比例配置，涉及到计息办法也不同，部分行业只计半年息。

**记账办法**：具体参照下文「在职死亡」的个人账户继承额计算办法。

---

### 6. 各项待遇计算办法

```
月养老金 = 基础养老金 + 个人账户养老金 + 过渡性养老金 + 限高金额
```

#### 6.1 基础养老金

```
基础养老金 = (参保人员退休时本省上一年度在岗职工月平均工资 W + 本人指数化月平均缴费工资) ÷ 2 × 累计缴费年限 N × 1%
```

- `N` = 累计缴费年限（折算为年，剩余月数规则：1-6个月按0.5年，7-11个月按1年计算）

#### 6.2 个人账户养老金

```
个人账户养老金 = 退休时个人账户储存额 ÷ 本人退休年龄相应的计发月数
```

**计发月数**：按照对应的退休年龄配置相应的计发月数（同机关保）。

#### 6.3 过渡性养老金

```
过渡性养老金 = 本人指数化月平均缴费工资 × 建账前的累计缴费年限 × 1.3%
```

- 建账前的累计缴费年限：缴费年限累计月数的尾数为1-6个月的按0.5年计算，7-11个月按1年计算。

#### 6.4 限高金额（保底机制）

```
限高金额 = 当地最新的最低工资 × 60% - (基础养老金 + 个人账户养老金 + 过渡性养老金)
```

**规则**：最终核定出来月养老金 **低于** 当地最新公布的最低工资标准的60%，补足该部分的限高金额。

---

### 7. 历年待遇调整

**调整人群**：针对上年度12月31日已按规定办理退休（含退职）手续并按月领取基本养老的退休人员。

根据近几年调整办法主要以下 **4种**：

| 调整类型 | 计算规则 |
|----------|----------|
| **定额部分调整** | 退休人员每月按固定金额调整 |
| **缴费年限挂钩部分调整** | 与退休人员本人缴费年限（含视同缴费年限，视同包含90年底前不含缴费年限）挂钩部分，月增加标准按退休人员本人缴费年限每满一年增发固定金额 |
| **养老金挂钩部分调整** | 与退休人员本人基本养老金挂钩部分，按本人上年度12月份发放基本养老金标准的固定百分比调整增加 |
| **70周岁增发调整** | 上年度1月1日至12月31日期间达到70周岁的退休人员，在本地定额调整、其它挂钩部分调整的基础上每人每月增发固定金额 |

> 注：若存在历史已调整过人员不再次调整。

---

### 8. 企业保特殊规则

1. **最低缴费年限**：累计缴费≥15年（180个月）方可按月领取基本养老金
2. **计发月数**：与机关保使用同一计发月数表
3. **女性退休年龄**：女工人50周岁，女干部55周岁（岗位满5年可转换）
4. **男性退休年龄**：一律60周岁

## 五、企业保 - 在职人员年度计息与转移接续

### 1. 在职人员年度计息

**计算公式**：

```
至本年底止个人帐户累计储存额 = 上年底止个人帐户累计储存额 × (1 + 本年记帐利率) + 本年记帐额本金 + 本年记帐额利息
```

**本年记帐额利息** 分两种情况：

| 到账时间 | 计息公式 |
|----------|----------|
| **2021年前（不含2021）** | 本年记帐额利息 = 本年记帐额本金 × 本年记帐利率<br>计息日期：为到账当年度1月 |
| **2021年后（含2021）** | 本年记帐额利息 = 本年记帐月积数 × 本年记帐利率 × １/12<br>本年记帐月积数 = ∑〔n月份记帐额 × (12 - n + 1)〕<br>(n为本年各记帐月份，且1 ≤ n ≤ 12) |

---

### 2. 转移接续

#### 2.1 转入

**计息年月**：

| 财务到账年份 | 计息规则 |
|--------------|----------|
| **2021年前（不含2021）** | 1998年1月1日前账户中个人缴费累计储存额、1998年1月1日至调转上年末个人账户累计储存额以及调转当年记入个人账户本金金额，计息年月都为财务到账当年度1月 |
| **2021年后（含2021）** | 1998年1月1日前账户中个人缴费累计储存额以及1998年1月1日至调转上年末个人账户累计储存额，计息年月为财务到账当年度1月 |

**调转当年记入个人账户本金金额**（2021年后）：

| 情况 | 计息规则 |
|------|----------|
| 调转当年存在补缴历年的缴费，转移信息表上应体现具体年月 | 按照异地到账的年月作为本地的开始计息年月 |
| 调转当年存在补缴历年的缴费，转移信息表上未体现具体年月 | 默认按照财务到账日期作为本地的开始计息年月 |

| 调转当年正常缴费，存在跨月 | 按月拆分缴费记录分别取对应的缴费年月作为本地的开始计息年月 |

#### 2.2 转出

```
基金转移额 = 统筹基金转移额 + 个人账户基金转移额
```

**统筹基金转移额**：

| 账户类型 | 计算公式 |
|----------|----------|
| 一般账户期间 | ∑月缴费基数 × 缴费月数 × 12%，求和范围为缴费起始时间在1998年1月及以后所有备注不包含"临时缴费账户"字样的记录，全部求和完成后再四舍五入 |
| 临时缴费账户期间 | ∑月缴费基数 × 缴费月数 × （12%、单位缴费比例两项中的大者），求和范围为所有备注含"临时缴费账户"字样的记录，全部求和完成后再四舍五入 |

**个人账户基金转移额**：

```
个人账户基金转移额 = 1998年1月1日前账户中个人缴费累计储存额 + 1998年1月1日至调转上年末个人账户累计储存额 + 调转当年记入个人账户本金金额
```

> 注：2021年1月开始实行按月计息办法执行生成对应的转移信息表，如果转出日期为2021年后（含2021年），若调转当年存在补缴历年的缴费，转移信息表上体现具体年月。

## 七、企业保 - 一次性待遇

### 1. 离退休死亡待遇

|----------|----------|

#### 1.2 丧葬费

| 人员类型/死亡日期 | 计算公式 |
|-------------------|----------|
| **离休人员** | 丧葬费 = 2 × 离退休人员死亡上年度的月社平工资 |
| **非离休人员，死亡日期 < 20210901** | 丧葬费 = 死亡上年度的月社平工资 × 2 |
| **非离休人员，死亡日期 ≥ 20210901** | 丧葬费 = 死亡时本省上一年度城镇居民月人均可支配收入 × 2 |

#### 1.3 一次性抚恤金

| 人员类型/死亡日期 | 计算公式 |
|-------------------|----------|
| **离休人员** | 一次性抚恤金 = 死亡上年度全国城镇居民最低生活保障线 × 2 + 40 × 基本离休费<br>基本离休费 = 离休费 + 抚恤附加标准 - 生活补助 - 地区补贴 - 生活补贴 - 地区津贴<br>（若选择不计算基本离休费，默认基本离休费 = 离休费） |
| **非离休人员，20200107 ≤ 死亡日期 < 20210901** | 一次性抚恤金 = 5 × 退休人员死亡时上一年度全省企业退休人员月人均养老金标准<br>（上一年度全省企业退休人员月人均养老金：由人社厅、财政厅公布，系统中配置） |
| **非离休人员，死亡日期 ≥ 20210901** | 抚恤金 = 死亡时本省上一年度城镇居民月人均可支配收入 × 发放月数<br><br>**发放月数计算**：<br>① 缴费年限 ≤ 15，发放月数 = 9<br>② 15 < 缴费年限，发放月数 = greatest(least(缴费年限 - 15 + 9, 24) - 领取养老金年限, 9)<br><br>缴费年限 = (建账前累计缴费月数 + 建账后累计缴费月数) / 12<br>领取养老金年限 = 实发月数 / 12<br>实发月数 = 应发月数 - 中断月数 - 追回月数<br>应发月数 = (死亡年月的年份 - 领取年月的年份) × 12 + 死亡年月的月份 - 领取年月的月份 + 1 |

> ⚠️ **重要说明**：涉及到年限计算待遇金额时，不满一年全部按照0计算（即 5年11月 也算作 5年）；涉及到缴费年限条件判断时，按照实际情况进行判断（即 5年1月 也算作大于不等于 5年）。

## 十、机关保 - 计算公式

### 老办法待遇

```
老办法待遇月计发标准 = (A + B + C) × M × Π(1+Gn-1)
```

**参数说明**：

| 参数 | 说明 |
|------|------|
| **A** | 2014年9月工作人员本人的基本工资标准（按人员类别不同组成不同）<br>- 公务员（参公人员）：职务工资 + 级别工资<br>- 事业单位工作人员：岗位工资 + 薪级工资<br>- 机关技术工人：技术等级工资 + 岗位工资<br>- 机关普通工人：岗位工资 |
| **B** | 2014年9月工作人员本人的职务职级（技术职称）等对应的退休补贴标准 |
| **C** | 按照国办发〔2015〕3号文件规定相应增加的退休费标准 |
| **M** | 工作人员退休时工作年限对应的老办法计发比例（见下表） |
| **G~n-1~** | 参考第n－1年在岗职工工资增长等因素确定的工资增长率，n∈〔2015，N〕，G~2014~＝0；N为退休年度 |

**计发比例M对照表**：

| 工作年限 | 退休（公务员/事业单位/机关工人） | 退职（事业单位/机关工人） |
|----------|-----------------------------------|---------------------------|
| 工作年限 ≥ 35年 | 90% | 70% |
| 30年 ≤ 工作年限 ＜ 35年 | 85% | - |
| 20年 ≤ 工作年限 ＜ 30年 | 80% | - |
| 10年 ≤ 工作年限 ＜ 20年 | 70% | 60% |
| 工作年限 ＜ 10年 | 50% | 50% |

**计算规则**：老办法待遇每次运算结果 X 向上取整，再返回继续计算。

### 新办法待遇

```
基本养老金 = 基础养老金(Y1) + 过渡性养老金(Y2) + 个人账户养老金(Y3)  
新办法待遇 = 基本养老金 + 职业年金(Y4)
```

#### 1. 计算实际平均缴费指数

实际缴费指数 = 缴费基数 ÷ 缴费到账时间对应的上年度社平工资

**不同时间段处理规则：

| 费款期 | 处理规则 |
|--------|----------|
| 1990年12月前 | 均按 1 计算 |
| 1991年1日至1995年12月 | 实际缴费指数 ≤ 0.75，按 0.75 计算；实际缴费指数 ＞ 0.75，按实际计算 |
| 1996年1月 - 2014年9月 | 按费款期对应的到账时间/到账对应的上年度社平得到缴费指数 |
| 2014年10月 - 2018年12月 | - A：省内机关保缴费，2018年12月前补交（含转移数据）：按费款期/费款期对应的上年度社平<br>- B：机关保缴费，2019年1月起补交：按费款期对应的到账时间/到账时间对应的上年度社平<br>- C：企业保缴费：按费款期到账年度的缴费基数/缴费到账上年度社平 |
| 2019年1月起 | 按费款期对应的到账时间/到账对应的上年度社平得到缴费指数 |

**特殊规则**：
- 如有省外转入（非视同缴费区间），分别按省外社平和省内社平计算缴费指数，**就高选择**。
- 厦门特殊情况：实际缴费指数计算最早从1997年7月开始。

#### 2. 计算基础养老金 Y1

```
本人平均缴费工资指数 T = (视同缴费月数 × 视同缴费指数 + 实际缴费指数总和) ÷ (视同缴费月数 + 实际缴费月数)
基础养老金 Y1 = (参保人员退休时本省上年度在岗职工月平均工资 W + W × T) ÷ 2 × (实际缴费月数 + 视同缴费月数) ÷ 12 × 1%
           = W × (1 + T) / 2 × (S1+S3)/12 × 1%
```

其中：
- T3 = 视同缴费指数 = 基准视同缴费指数 × 调节系数（调节系数按待遇领取地选取）
- S1 = 实际缴费月数
- S3 = 视同缴费月数
- W = 退休时本省上年度在岗职工月平均工资（或计发基数）
- 月数折算规则：剩余月数 6个月以内按0.5年，7个月以上按1年计算

#### 3. 计算过渡性养老金 Y2

```
过渡性养老金 Y2 = 参保人员退休时本省上年度在岗职工月平均工资 W × 视同缴费指数 T3 × (视同缴费月数 S3 / 12) × 1.3%
```

#### 4. 计算个人账户养老金 Y3

```
个人账户养老金 Y3 = 退休时本人基本养老保险个人账户累计储存额 ÷ 计发月数
```

#### 5. 计算职业年金 Y4

```
职业年金 Y4 = 退休时本人职业年金账户储存额 ÷ 计发月数
```

**说明**：
- 职业年金储存额 = （正常缴费账户份额 + 记实缴费账户份额） × 单位净值（待遇计算时点） + （正常缴费账户金额 + 记实缴费账户金额） - （退费金额）
- 企业年金不参与新老办法比对
- **新老办法比对使用**：**税前**金额参与比对，表单体现税后金额

---

### 新老办法待遇比对（过渡期）

```
① 老办法 = (A + B + C) × M × Π(1+Gn-1)
② 新办法 = 基础养老金 + 个人账户养老金 + 过渡性养老金 + 职业年金

最终待遇 = ① , 当 ② ≤ ①  
最终待遇 = ① + (② - ①) × [(Y-2014) × 10%] , 当 ② ＞ ①  (2015 ≤ Y ≤ 2024)
```

**特殊封顶规则**（闽人社文〔2019〕236号）：退休人员最终核定的退休当月养老金不得高于上限，如果高出，差额部分从过渡性养老金中扣减，过渡性养老金不够扣减的，其余部分再从基础养老金中扣减。

### 最终待遇明细

待遇明细体现为：
1. 基础养老金
2. 过渡性养老金
3. 个人账户养老金
4. 机关事业新待遇补差养老金（2024.10.1起退休为0）
5. 职业年金待遇

**特殊说明（厦门）**：新老办法对比及限高计算后，最终待遇与新办法之间的待遇差额全部在过渡性养老金调整（无机关事业新待遇补差养老金项目）。

## 十二、机关保 - 业务校验规则

### 1. 业务逻辑校验

1. **缴费年限校验**：累计缴费月数（含补缴+视同）≥ 180个月（15年），否则提示「累计缴费年限不足15年」并阻断。

2. 过渡期退休，调整后2014年9月职务/岗位与退休时不一致，作出提醒仍允许继续操作。

3. 视同缴费起始时间早于参加工作时间，或视同缴费截止时间晚于2014年9月，或视同缴费年月与工龄中断年月交叉重叠，作出提醒并阻断。

4. 待遇开始年月必须晚于退休年月，否则提醒并阻断。

5. **未缴费区间校验**：入伍时间至退休时间，扣除视同缴费区间和中断工龄区间后，剩余区间提示未缴费区间，可生成《未缴费情况告知表》：
   - 过渡期内退休：提醒后可选择执行老办法或新老办法比对
   - 过渡期后退休：提醒后可继续操作

6. **职业年金状态校验**：
   - 过渡期内退休：2014年10月起职业年金有未缴费、未记实、未归集状态，提醒后可选择是否老办法计算
   - 过渡期后退休：提醒后可继续操作

7. **业务次数校验**：待遇核定只允许经办一次：
   - 未生成待遇支付计划（或生成后已回退）且后续操作均已回退 → 允许回退
   - 已生成待遇支付计划或存在未回退的后续业务 → 不允许回退，提醒并阻断

8. **退休年龄校验**：
   - 正常退休：男满60，女干部满55，女职工满50，否则阻断
   - 提前退休（仅限公务员/参公）：工作年限满30年 或 工作年限满20年且距离退休不足5年，否则阻断
   - 特殊工种提前退休：男满55，女满45，否则阻断
   - 因病退休：男满55，女干部满50，女职工满45，否则阻断

9. 该人员身份证下有多个年金账户未合并，提示「该人员身份证下有多个年金账户未合并，个人编号：xxx」，阻断。

### 2. 业务协同校验

1. 与企业保、城居保比对，是否已存在待遇信息（已转出不比对），提醒后仍可继续操作。

2. 与公安系统数据比对，校验姓名、证件号码信息，提醒后仍可继续操作。

3. 与司法系统数据比对，是否存在服刑信息，提醒后仍可继续操作。

4. 从福建省机关事业单位人事管理平台提取：人员类别、2014年9月职务/岗位/级别/薪级/档次、退休时职务/岗位/级别/薪级/档次、老办法计发比例、特殊人员信息、待遇开始时间等数据（厦门市不提取，直接取值老办法待遇）。

5. 默认根据身份证号码自动调取社会保障卡数据库该人员的账户信息，无账户信息才允许手工录入。

## 十四、机关保 - 业务流程

1. **业务申请**：申请人向社保经办机构提出为退休人员计算退休待遇，提交申报材料。

2. **业务受理**：核对材料是否齐全完整，审核材料是否真实有效，审核退休人员缴费数据是否完整；不符合条件的不予受理，并一次性告知原因。

3. **业务经办**：
   - 进行业务逻辑校验和业务协同校验
   - 点击计算，按照上述公式计算待遇
   - 调用机关事业单位视同缴费年限个人缴费部分一次性退还模块，生成一次性退还金额并体现在计发表上

4. **业务审核**：审核材料是否合法合规，审核是否符合办理条件，审核参保人员信息和计算结果是否有误；审核不通过一次性告知原因。

5. **业务审批**：审批通过/不通过，不通过退回审核节点。

6. **结果反馈**：审批完成后，通过闽政通APP、电子社保卡或短信通知：
   - 参保单位经办人员："{单位名称} {姓名}于{年份}年{月份}月办理完待遇核定业务，请您及时来领取计发表或登录平台自行打印。"
   - 职工本人：根据情况有不同格式：
     - 按老办法计算无补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金预发X元，从X月开始发放。"
     - 按老办法计算有补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金预发X元，含补发金额，X月发放基本养老金X元，次月恢复正常发放金额。"
     - 有职业年金无补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金X元，职业年金待遇X元，从X月开始发放。"
     - 有职业年金有补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金X元，职业年金待遇X元；含补发金额，X月发放基本养老金X元，职业年金待遇X元。次月恢复正常发放金额。"

## 十七、城乡居民基本养老保险 - 退休待遇计算规则

本系统支持城乡居民养老保险（居民保）退休待遇测算，计算规则依据《福建省人民政府关于城乡居民基本养老保险制度的实施意见》（闽政〔2014〕40号）及后续调整政策。

---

### 1. 领取条件

- 年满 **60周岁**
- 累计缴费年限 ≥ **15年**
- 未领取职工基本养老保险待遇或其他国家规定的养老待遇

---

### 2. 待遇构成

```
月领取养老金 = 基础养老金 + 个人账户养老金 + 缴费年限养老金
```

---

### 3. 计算公式

#### （1）基础养老金

**计算公式**：按当地当年政府公布标准计发（固定金额，不与缴费指数挂钩）

**政策规则**：
- 省级政府确定全省最低基础养老金标准
- 缴费年限 **超过15年** 的，每多缴一年，每月 **增发不低于5元** 基础养老金
- 对 **65周岁及以上** 参保城乡老年居民，每月额外加发不低于 **5元** 的基础养老金（高龄倾斜）

---

#### （2）个人账户养老金

```
个人账户养老金 = 个人账户全部储存额 ÷ 139
```

**参数说明**：
- 计发月数固定为 **139**（居民保统一60周岁退休）
- 个人账户储存额包含：
  - 个人缴费累计额
  - 政府缴费补贴累计额
  - 集体补助累计额
  - 利息收益

**政府缴费补贴标准**（福建省最低标准）：

| 缴费档次（元/年） | 政府补贴标准（元/年） |
|-------------------|-----------------------|
| 100               | 30                    |
| 200               | 40                    |
| 300               | 50                    |
| 400               | 60                    |
| 500               | 70                    |
| 1000              | 100                   |
| 2000              | 150                   |
| 3000              | 200                   |

> 补缴保费不享受政府缴费补贴。

---

#### （3）缴费年限养老金（福建省特有）

```
缴费年限养老金 = 累计缴费年限 × 2元/年
```

**说明**：福建省对参保居民按月加发缴费年限养老金，标准为每缴费一年每月不低于2元。

---

### 4. 特殊规则

| 项目 | 规则 |
|------|------|
| **领取年龄** | 不分男女，统一 **60周岁** |
| **最低缴费年限** | 累计满 **15年** |
| **补缴政策** | 达到60周岁时缴费不足15年的，可一次性补缴，补缴不享受政府补贴 |
| **个人账户继承** | 参保人死亡，个人账户余额可依法继承 |
| **地方标准** | 全省统一计算公式，基础养老金标准按政策调整输入 |

无计算规则，直接根据前台经办人员填写生成。

### 2. 伤残待遇核定

#### 2.1 伤残津贴

```
伤残津贴 = 本人平均缴费工资 × 工伤定期待遇参数
```

**本人平均缴费工资**：

| 参保类型 | 计算规则 |
|----------|----------|
| 职工参保 | 工伤发生日期前12个月平均缴费基数<br>注：如果工伤发生前未达12个月按照具体月数取平均缴费基数 |
| 工程参保 | 工伤发生日期上一年度月社平工资（按地市） |

**工伤定期待遇参数**：

| 伤残等级 | 系数 |
|----------|------|
| 一级 | 0.9 |
| 二级 | 0.85 |
| 三级 | 0.8 |
| 四级 | 0.75 |

#### 2.2 一次性伤残补助金

```
一次性伤残补助金 = 本人平均缴费工资 × 工伤定期待遇参数
```

> 注：老工伤人员不核定一次性伤残补助金，根据人员身份进行判断。

#### 2.3 生活护理费

```
生活护理费 = 护理鉴定日期上年度社平工资 × 护理依赖等级参数
```

**护理依赖等级参数**：

### 3. 一次性医疗补助金

工伤5-10级，解除或终止劳动关系时享受。

```
工伤一次性医疗补助金 = 上年度社平工资 × 最终月数 × (1 + 职业病因子)
```

**参数计算**：

| 参数 | 计算公式 |
|------|----------|
| 解除或终止劳动关系时年数 | （解除或终止劳动关系日期 - 出生日期的月数） / 12<br>注：结果值四舍五入保留两位小数 |
| 年限 | 所在统筹地区最后一次公布的人口平均预期寿命 - 解除或终止劳动关系时年数<br>注：结果值向上取整 |
| 计算年龄月数 | 年限 × 比例参数<br>比例参数：五级 0.7，六级 0.6，七级 0.4，八级 0.3，九级 0.2，十级 0.1 |
| 最终月数 | 取「计算年龄月数」与「保底月数」中的最大值<br>保底月数：五级 15，六级 15，七级 10，八级 10，九级 5，十级 3 |
| 职业病因子 | 当「工伤类别」为「职业中毒」、「尘肺」或「其他职业病」时等于0.3，否则为0 |

### 4. 伤残津贴补差

领取伤残津贴人员已退休领取养老：

- 若伤残津贴 **高于** 养老金部分，伤残津贴补差金额 = 伤残津贴 - 养老金，并终止原伤残津贴定期待遇
- 若伤残津贴 **低于** 养老金部分，无伤残津贴补差金额，并终止伤残津贴定期待遇

### 5. 工伤人员死亡待遇核定

#### 5.1 一次性工亡补助金

```
一次性工亡补助金 = 工亡补助金系数 × 上年度全国城镇居民可支配收入
```

- 工亡补助金系数 = 20

#### 5.2 1-4级病亡

1-4级病亡待遇只有丧葬费：

```
丧葬费 = 死亡日期上年度当地社平工资 × 6
```

> 注：老工伤职工不享受丧葬费。

#### 5.3 遗属待遇

1-4级病亡人员或工亡人员死亡后亲属办理遗属待遇：

```
待遇金额 = 工伤死亡人员工资 × 百分比
```

> 多人享受待遇百分比之和 < 1。
