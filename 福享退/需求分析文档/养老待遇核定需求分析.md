# 福享退 - 养老待遇核定需求分析

## 一、项目整体功能

福享退是福建省退休待遇测算微信小程序，支持**机关保**和**企业保**参保人员退休待遇测算与核定，包含两大功能模块：

1. **参保人自助测算**（面向公众）：
   - 用户输入身份证号码（社会保障号）
   - 系统自动获取出生日期、性别、历年缴费明细
   - 自动预测**退休时间**，计算**距离退休还有多久**
   - 根据参保类型（机关保/企业保）计算预测退休后的养老待遇标准
   - 让参保人提前了解自己能拿多少养老金

2. **养老待遇核定**（面向社保经办机构，本需求文档）：
   - 改革后（2014年10月1日起）在职参保人员获批退休后，满足待遇申领计算条件时，在此核定应领取的退休待遇
   - 生成《基本养老保险参保人员基本养老金计发表》
   - 支持机关事业养老保险和企业养老保险

## 三、企业职工基本养老保险 - 退休待遇计算规则

企业职工基本养老保险待遇计算根据参保时间分为三种情况：

### 1. 分类规则

| 类型 | 参保时间 | 退休时间 | 计算方式 |
|------|----------|----------|----------|
| **老人** | 2006年1月1日前退休 | - | 按原规定计发 |
| **中人** | 2006年1月1日前参保 | 2006年1月1日后退休 | 基础养老金 + 个人账户养老金 + 过渡性养老金 |
| **新人** | 2006年1月1日后参保 | - | 基础养老金 + 个人账户养老金 |

### 2. 计算公式

#### （1）基础养老金

```
基础养老金 = (参保人员退休时本省上年度在岗职工月平均工资 W + 本人指数化月平均缴费工资) ÷ 2 × 累计缴费年限 N × 1%
         = W × (1 + T) / 2 × N × 1%
```

其中：
- `W` = 退休时本省上年度在岗职工月平均工资
- `T` = 本人平均缴费工资指数 = 各年度缴费指数之和 ÷ 缴费年限
- `N` = 累计缴费年限（折算为年，剩余月数规则：6个月以内按0.5年，7个月以上按1年计算）

**缴费指数计算规则**：
- 当年缴费指数 = 当年本人缴费基数 ÷ 当年本省在岗职工平均工资
- 参保人员累计缴费年限不满整年的，按月计算缴费指数

#### （2）个人账户养老金

```
个人账户养老金 = 退休时个人账户累计储存额 ÷ 计发月数
```

**计发月数**：根据退休年龄按国家统一表选取（同机关保）

#### （3）过渡性养老金（中人）

```
过渡性养老金 = 参保人员退休时本省上年度在岗职工月平均工资 W × 本人平均缴费指数 T × 建立个人账户前的缴费年限 N1 × 1.3%
```

- `N1` = 建立个人账户前的缴费年限（即 2006年1月前的缴费年限）

#### （4）过渡性调节金（中人）

```
过渡性调节金 = 基准调节金 + 平均缴费工资指数 × 缴费年限 × 调节系数
```

> 福建省过渡性调节金标准按闽劳社〔2006〕对应文件执行

### 3. 企业保特殊规则

1. **最低缴费年限**：累计缴费≥15年（180个月）方可按月领取基本养老金
2. **计发月数**：与机关保使用同一计发月数表
3. **女性退休年龄**：女工人50周岁，女干部55周岁
4. **男性退休年龄**：一律60周岁

## 二、计算规则分类

按退休时间分为两类：

### 1️⃣ 过渡期（2014.10.1 - 2024.9.30）退休
- 分别计算**老办法待遇**和**新办法待遇**
- **保低限高规则**：
  - 新办法（含职业年金） ≤ 老办法 → 按老办法发放
  - 新办法（含职业年金） > 老办法 → 老办法 + 超出部分 × 计发比例  
    计发比例 = (退休年份 - 2014) × 10% （逐年递增10%）
- 若基本养老保险或职业年金不满足计算条件，可仅按老办法预发，暂不计算新办法
- 关联模块：职业年金按月领取、机关事业单位视同缴费年限个人缴费部分一次性退还、统筹外待遇领取模块
- **特殊规则**：2019年1月至2024年9月30日期间退休且视同缴费指数≥1，还需根据闽人社文〔2019〕236号计算确认最终养老待遇。

### 2️⃣ 过渡期后（2024.10.1起）退休
- 只核定新办法待遇
- 新办法待遇含养老金待遇和职业年金待遇
- 关联模块同过渡期

## 三、计算公式

### 老办法待遇

```
老办法待遇月计发标准 = (A + B + C) × M × Π(1+Gn-1)
```

**参数说明**：

| 参数 | 说明 |
|------|------|
| **A** | 2014年9月工作人员本人的基本工资标准（按人员类别不同组成不同）<br>- 公务员（参公人员）：职务工资 + 级别工资<br>- 事业单位工作人员：岗位工资 + 薪级工资<br>- 机关技术工人：技术等级工资 + 岗位工资<br>- 机关普通工人：岗位工资 |
| **B** | 2014年9月工作人员本人的职务职级（技术职称）等对应的退休补贴标准 |
| **C** | 按照国办发〔2015〕3号文件规定相应增加的退休费标准 |
| **M** | 工作人员退休时工作年限对应的老办法计发比例（见下表） |
| **G~n-1~** | 参考第n－1年在岗职工工资增长等因素确定的工资增长率，n∈〔2015，N〕，G~2014~＝0；N为退休年度 |

**计发比例M对照表**：

| 工作年限 | 退休（公务员/事业单位/机关工人） | 退职（事业单位/机关工人） |
|----------|-----------------------------------|---------------------------|
| 工作年限 ≥ 35年 | 90% | 70% |
| 30年 ≤ 工作年限 ＜ 35年 | 85% | - |
| 20年 ≤ 工作年限 ＜ 30年 | 80% | - |
| 10年 ≤ 工作年限 ＜ 20年 | 70% | 60% |
| 工作年限 ＜ 10年 | 50% | 50% |

**计算规则**：老办法待遇每次运算结果 X 向上取整，再返回继续计算。

---

### 新办法待遇

```
基本养老金 = 基础养老金(Y1) + 过渡性养老金(Y2) + 个人账户养老金(Y3)  
新办法待遇 = 基本养老金 + 职业年金(Y4)
```

#### 1. 计算实际平均缴费指数

实际缴费指数 = 缴费基数 ÷ 缴费到账时间对应的上年度社平工资

**不同时间段处理规则：

| 费款期 | 处理规则 |
|--------|----------|
| 1990年12月前 | 均按 1 计算 |
| 1991年1日至1995年12月 | 实际缴费指数 ≤ 0.75，按 0.75 计算；实际缴费指数 ＞ 0.75，按实际计算 |
| 1996年1月 - 2014年9月 | 按费款期对应的到账时间/到账对应的上年度社平得到缴费指数 |
| 2014年10月 - 2018年12月 | - A：省内机关保缴费，2018年12月前补交（含转移数据）：按费款期/费款期对应的上年度社平<br>- B：机关保缴费，2019年1月起补交：按费款期对应的到账时间/到账时间对应的上年度社平<br>- C：企业保缴费：按费款期到账年度的缴费基数/缴费到账上年度社平 |
| 2019年1月起 | 按费款期对应的到账时间/到账对应的上年度社平得到缴费指数 |

**特殊规则**：
- 如有省外转入（非视同缴费区间），分别按省外社平和省内社平计算缴费指数，**就高选择**。
- 厦门特殊情况：实际缴费指数计算最早从1997年7月开始。

#### 2. 计算基础养老金 Y1

```
本人平均缴费工资指数 T = (视同缴费月数 × 视同缴费指数 + 实际缴费指数总和) ÷ (视同缴费月数 + 实际缴费月数)
基础养老金 Y1 = (参保人员退休时本省上年度在岗职工月平均工资 W + W × T) ÷ 2 × (实际缴费月数 + 视同缴费月数) ÷ 12 × 1%
           = W × (1 + T) / 2 × (S1+S3)/12 × 1%
```

其中：
- T3 = 视同缴费指数 = 基准视同缴费指数 × 调节系数（调节系数按待遇领取地选取）
- S1 = 实际缴费月数
- S3 = 视同缴费月数
- W = 退休时本省上年度在岗职工月平均工资（或计发基数）
- 月数折算规则：剩余月数 6个月以内按0.5年，7个月以上按1年计算

#### 3. 计算过渡性养老金 Y2

```
过渡性养老金 Y2 = 参保人员退休时本省上年度在岗职工月平均工资 W × 视同缴费指数 T3 × (视同缴费月数 S3 / 12) × 1.3%
```

#### 4. 计算个人账户养老金 Y3

```
个人账户养老金 Y3 = 退休时本人基本养老保险个人账户累计储存额 ÷ 计发月数
```

#### 5. 计算职业年金 Y4

```
职业年金 Y4 = 退休时本人职业年金账户储存额 ÷ 计发月数
```

**说明**：
- 职业年金储存额 = （正常缴费账户份额 + 记实缴费账户份额） × 单位净值（待遇计算时点） + （正常缴费账户金额 + 记实缴费账户金额） - （退费金额）
- 企业年金不参与新老办法比对
- **新老办法比对使用**：**税前**金额参与比对，表单体现税后金额

---

### 新老办法待遇比对（过渡期）

```
① 老办法 = (A + B + C) × M × Π(1+Gn-1)
② 新办法 = 基础养老金 + 个人账户养老金 + 过渡性养老金 + 职业年金

最终待遇 = ① , 当 ② ≤ ①  
最终待遇 = ① + (② - ①) × [(Y-2014) × 10%] , 当 ② ＞ ①  (2015 ≤ Y ≤ 2024)
```

**特殊封顶规则**（闽人社文〔2019〕236号：退休人员最终核定的退休当月养老金不得高于上限，如果高出，差额部分从过渡性养老金中扣减，过渡性养老金不够扣减的，其余部分再从基础养老金中扣减。

### 最终待遇明细

待遇明细体现为：
1. 基础养老金
2. 过渡性养老金
3. 个人账户养老金
4. 机关事业新待遇补差养老金（2024.10.1起退休为0）
5. 职业年金待遇

**特殊说明（厦门）**：新老办法对比及限高计算后，最终待遇与新办法之间的待遇差额全部在过渡性养老金调整（无机关事业新待遇补差养老金项目）。

## 五、业务校验规则

### 1. 业务逻辑校验

1. **缴费年限校验：累计缴费月数（含补缴+视同）≥ 180个月（15年），否则提示「累计缴费年限不足15年」并阻断。

2. 过渡期退休，调整后2014年9月职务/岗位与退休时不一致，作出提醒仍允许继续操作。

3. 视同缴费起始时间早于参加工作时间，或视同缴费截止时间晚于2014年9月，或视同缴费年月与工龄中断年月交叉重叠，作出提醒并阻断。

4. 待遇开始年月必须晚于退休年月，否则提醒并阻断。

5. **未缴费区间校验：入伍时间至退休时间，扣除视同缴费区间和中断工龄区间后，剩余区间提示未缴费区间，可生成《未缴费情况告知表》：
   - 过渡期内退休：提醒后可选择执行老办法或新老办法比对
   - 过渡期后退休：提醒后可继续操作

6. **职业年金状态校验**：
   - 过渡期内退休：2014年10月起职业年金有未缴费、未记实、未归集状态，提醒后可选择是否老办法计算
   - 过渡期后退休：提醒后可继续操作

7. **业务次数校验：待遇核定只允许经办一次：
   - 未生成待遇支付计划（或生成后已回退）且后续操作均已回退 → 允许回退
   - 已生成待遇支付计划或存在未回退的后续业务 → 不允许回退，提醒并阻断

8. **退休年龄校验**：
   - 正常退休：男满60，女干部满55，女职工满50，否则阻断
   - 提前退休（仅限公务员/参公）：工作年限满30年 或 工作年限满20年且距离退休不足5年，否则阻断
   - 特殊工种提前退休：男满55，女满45，否则阻断
   - 因病退休：男满55，女干部满50，女职工满45，否则阻断

9. 该人员身份证下有多个年金账户未合并，提示「该人员身份证下有多个年金账户未合并，个人编号：xxx，阻断。

### 2. 业务协同校验

1. 与企业保、城居保比对，是否已存在待遇信息（已转出不比对），提醒后仍可继续操作。

2. 与公安系统数据比对，校验姓名、证件号码信息，提醒后仍可继续操作。

3. 与司法系统数据比对，是否存在服刑信息，提醒后仍可继续操作。

4. 从福建省机关事业单位人事管理平台提取：人员类别、2014年9月职务/岗位/级别/薪级/档次、退休时职务/岗位/级别/薪级/档次、老办法计发比例、特殊人员信息、待遇开始时间等数据（厦门市不提取，直接取值老办法待遇）。

5. 默认根据身份证号码自动调取社会保障卡数据库该人员的账户信息，无账户信息才允许手工录入。

## 七、业务流程

1. **业务申请**：申请人向社保经办机构提出为退休人员计算退休待遇，提交申报材料。

2. **业务受理**：核对材料是否齐全完整，审核材料是否真实有效，审核退休人员缴费数据是否完整；不符合条件的不予受理，并一次性告知原因。

3. **业务经办**：
   - 进行业务逻辑校验和业务协同校验
   - 点击计算，按照上述公式计算待遇
   - 调用机关事业单位视同缴费年限个人缴费部分一次性退还模块，生成一次性退还金额并体现在计发表上

4. **业务审核**：审核材料是否合法合规，审核是否符合办理条件，审核参保人员信息和计算结果是否有误；审核不通过一次性告知原因。

5. **业务审批**：审批通过/不通过，不通过退回审核节点。

6. **结果反馈**：审批完成后，通过闽政通APP、电子社保卡或短信通知：
   - 参保单位经办人员："{单位名称} {姓名}于{年份}年{月份}月办理完待遇核定业务，请您及时来领取计发表或登录平台自行打印。"
   - 职工本人：根据情况有不同格式：
     - 按老办法计算无补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金预发X元，从X月开始发放。"
     - 按老办法计算有补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金预发X元，含补发金额，X月发放基本养老金X元，次月恢复正常发放金额。"
     - 有职业年金无补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金X元，职业年金待遇X元，从X月开始发放。"
     - 有职业年金有补发："您的退休待遇于XXXX年XX月办理完毕，基本养老金X元，职业年金待遇X元；含补发金额，X月发放基本养老金X元，职业年金待遇X元。次月恢复正常发放金额。"
