## 1. 项目概述

### 1.1 功能定位

**福享退 V1.0** 是面向福建省企业职工养老保险参保人的微信小程序，核心功能：

- 用户上传《基本养老个人历年缴费明细》PDF文件
- 系统自动解析缴费明细并展示
- 用户核对并补充相关信息
- 系统自动计算退休待遇并展示结果

### 1.2 技术栈

| 端 | 技术 |
|----|------|
| 前端 | 微信小程序 |
| 后端 | Spring Boot |
| PDF解析 | Apache PDFBox（Java）或 pdfplumber（Python） |

## 4. 企业养老待遇计算规则

### 4.1 退休年龄规定

| 退休身份 | 正常退休年龄 | 特殊说明 |
|----------|------------|---------|
| 男性 | 60周岁 | |
| 女工人 | 50周岁 | |
| 女干部 | 55周岁 | |

### 4.2 缴费年限认定

```
累计缴费年限 = 实际缴费年限 + 视同缴费年限
```

**年限折算规则**：
- 累计缴费月数尾数 1-6个月 = 0.5年
- 累计缴费月数尾数 7-11个月 = 1年

### 4.3 平均缴费指数计算

```
平均缴费指数 = 各年度缴费指数之和 ÷ 缴费年限
```

**年度缴费指数** = 当年月平均缴费基数 ÷ 当年度的月社平工资

- 2020年度后退休采用斜比方法：当年度月平均缴费基数 ÷ 上年度的月缴费基数上下限
- 1990年底前的每年度缴费指数统一按 1 计算

### 4.4 待遇计算公式

```
月养老金 = 基础养老金 + 个人账户养老金 + 过渡性养老金 + 缴费年限养老金
```

**4.4.1 基础养老金**

```
基础养老金 = (参保人员退休时本省上一年度在岗职工月平均工资 + 本人指数化月平均缴费工资) ÷ 2 × 累计缴费年限 × 1%

其中：
本人指数化月平均缴费工资 = 退休时上年度在岗职工月平均工资 × 本人平均缴费指数
```

**4.4.2 个人账户养老金**

```
个人账户养老金 = 退休时个人账户累计储存额 ÷ 计发月数
```

**计发月数表**（常用值）：

| 退休年龄 | 计发月数 |
|----------|---------|
| 50岁 | 195 |
| 55岁 | 170 |
| 60岁 | 139 |

**个人账户储存额估算规则**（用户不填写时使用）：
- 按各年度缴费基数 × 8%（个人账户缴费比例）累计计算
- 加上估算的记账利息

**4.4.3 过渡性养老金（中人）**

适用范围：2006年1月前参保并有视同缴费年限的人员

```
过渡性养老金 = 本人指数化月平均缴费工资 × 建账前的累计缴费年限 × 1.3%
```

**4.4.4 缴费年限养老金（福建省特有）**

```
缴费年限养老金 = 累计缴费年限 × 每年1元标准
```

> 注：具体标准按政策调整，暂按每年1元/月计算

### 4.5 待遇保底机制

```
最终月养老金低于当地最新公布的最低工资标准的60%，补足到最低工资标准的60%。
```

### B. PDF解析技术要点

1. 采用 **Apache PDFBox** 进行文本提取
2. 表格数据采用 **按列定位** 方式解析
3. 跨行的单位名称需要智能合并相邻行
4. 多页PDF每页重复表头，需识别并跳过
5. 缴费记录按时间倒序排列，解析后可正序重排
