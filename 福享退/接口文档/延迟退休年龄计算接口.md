# 延迟退休年龄计算接口文档

## 接口概述

根据**出生年月**和**人员类别**，自动计算退休时间，包含延迟退休政策和弹性退休范围。

---

## 接口详情

### 接口地址
```
GET /api/calculate/retire-date
```

### 请求参数

| 参数名 | 类型 | 必填 | 说明 | 示例 |
|--------|------|------|------|------|
| `birth_date` | string | 是 | 出生日期（YYYY-MM-DD） | `1982-11-01` |
| `person_type` | int | 是 | 人员类别：11=男职工，12=女干部（55岁退休），13=女工人（50岁退休） | `13` |

---

### 响应参数

| 参数名 | 类型 | 说明 | 示例 |
|--------|------|------|------|
| `code` | int | 状态码：200=成功 | `200` |
| `message` | string | 提示信息 | `计算成功` |
| `data` | object | 返回数据对象 | |
| `data.birth_date` | string | 出生日期 | `1982-11-01` |
| `data.person_type` | int | 人员类别 | `13` |
| `data.person_type_name` | string | 人员类别名称 | `女工人` |
| `data.original_retire_age` | int | 原法定退休年龄（岁） | `50` |
| `data.delay_months` | int | 延迟月数 | `48` |

| `data.elastic_early_date` | string | 弹性最早退休日期（-3年） | `2033-11-01` |
| `data.elastic_late_date` | string | 弹性最晚退休日期（+3年） | `2039-11-01` |

## 计算逻辑

### 核心算法

```java
// 1. 解析出生日期
LocalDate birthDate = LocalDate.parse(request.getBirthDate());

// 2. 提取出生年份和月份
int birthYear = birthDate.getYear();
int birthMonth = birthDate.getMonthValue();

// 3. 查询延迟退休年龄对照表（优先匹配精确月份，其次匹配全年通用数据）
SysRetireAgeMapping mapping = mapper.selectOne(
  new LambdaQueryWrapper<SysRetireAgeMapping>()
    .eq(SysRetireAgeMapping::getPersonType, request.getPersonType())
    .eq(SysRetireAgeMapping::getBirthYear, birthYear)
    .and(wrapper -> wrapper
      .eq(SysRetireAgeMapping::getBirthMonth, birthMonth)
      .or()
      .eq(SysRetireAgeMapping::getBirthMonth, 0)
    )
    .orderByAsc(SysRetireAgeMapping::getBirthMonth)
    .last("LIMIT 1")
);

// 4. 计算改革后法定退休日期
LocalDate reformRetireDate = birthDate
    .plusYears(mapping.getReformRetireAgeYear())
    .plusMonths(mapping.getReformRetireAgeMonth());

// 5. 计算弹性退休范围
LocalDate elasticEarlyDate = reformRetireDate.minusYears(3);
LocalDate elasticLateDate = reformRetireDate.plusYears(3);
```

### 延迟政策说明

| 人员类别 | 原退休年龄 | 目标退休年龄 | 每年延迟 | 实施起始年份 |
|---------|----------|------------|---------|------------|
| 男职工（11） | 60岁 | 65岁 | 3个月 | 1965年出生 |
| 女干部（12） | 55岁 | 65岁 | 4个月 | 1970年出生 |
| 女工人（13） | 50岁 | 65岁 | 4个月 | 1976年出生 |

**弹性退休：** 可在改革后法定退休年龄基础上，提前3年或延迟3年退休。

## 数据库表结构

```sql
CREATE TABLE `sys_retire_age_mapping` (
  `id` bigint NOT NULL AUTO_INCREMENT COMMENT '主键ID',
  `person_type` tinyint NOT NULL COMMENT '人员类别：11=男职工，12=女干部55岁，13=女工人50岁',
  `birth_year` int NOT NULL COMMENT '出生年份',
  `birth_month` int NOT NULL DEFAULT 0 COMMENT '出生月份：0=全年通用，1-12=具体月份',
  `original_retire_age` int NOT NULL COMMENT '原法定退休年龄（岁）',
  `reform_retire_age_year` int NOT NULL COMMENT '改革后退休年龄（年）',
  `reform_retire_age_month` int NOT NULL DEFAULT 0 COMMENT '改革后退休年龄（月）',
  `delay_months` int NOT NULL COMMENT '延迟月数',
  `create_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
  `update_time` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_type_year_month` (`person_type`, `birth_year`, `birth_month`),
  KEY `idx_person_type` (`person_type`),
  KEY `idx_birth_year` (`birth_year`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='延迟法定退休年龄对照表';
```

---

## 注意事项

1. **数据库初始化：** 执行 `sys_retire_age_mapping_init.sql` 完成建表和数据初始化
2. **数据精度：** 当前按年份通用匹配（birth_month=0），后续可根据政策细化到具体月份
3. **政策更新：** 如国家政策调整，只需更新 `sys_retire_age_mapping` 表数据即可
4. **人员类别判断：** 前端需要让用户选择或根据参保信息判断是女干部还是女工人
