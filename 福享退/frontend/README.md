# 福享退 - 前端项目

福建省养老保险待遇智能测算平台前端项目

## 项目结构

```
frontend/
├── css/                    # 样式文件
│   ├── common.css          # 通用样式
│   └── index.css           # 页面样式
├── utils/                  # 工具函数
│   ├── storage.js          # 本地存储工具
│   ├── request.js          # 请求工具
│   └── common.js           # 通用工具函数
├── api/                    # API接口
│   ├── user.js             # 用户相关API
│   └── pension.js          # 养老金测算相关API
├── js/                     # 页面逻辑
│   ├── app.js              # 应用主逻辑
│   ├── calculate.js        # 测算相关逻辑
│   ├── history.js          # 历史记录逻辑
│   └── guide.js            # 指南相关逻辑
├── images/                 # 图片资源
├── components/             # 组件（预留）
└── index.html              # 入口页面
```

## 功能模块

### 1. 首页（Home）
- 核心测算入口（PDF测算）
- 手动测算入口
- 扩展分析（待遇调整预测、回本年龄等，V1.1开放）
- 历史记录入口
- 退休办理指南

### 2. PDF上传解析（Upload）
- 选择PDF文件
- 文件格式/大小校验
- 上传进度显示
- 解析缴费明细
- 示例数据体验

### 3. 缴费明细（Detail）
- 个人信息卡片展示
- 缴费明细列表（支持分页）
- 平均缴费基数等统计信息

### 4. 补充信息录入（Input）
- 人员类型选择（企业/机关事业）
- 性别选择
- 退休身份选择（工人/干部/特殊工种）
- 退休年龄输入
- 视同缴费年限输入
- 个人账户储存额输入

### 5. 测算结果（Result）
- 预计月养老金（主卡片）
- 基本信息摘要
- 待遇明细分解（基础+个人+过渡性）
- 详细计算过程（可展开）
- 多缴费方案对比
- 保存结果功能

### 6. 历史记录（History）
- 测算历史列表
- 点击查看详情
- 空状态提示

### 7. 退休办理指南（Guide）
- 办理条件说明
- 办理材料清单
- 福建省各地市社保经办机构地址电话
- 常见问题解答（FAQ）

## 技术特点

1. **纯HTML/CSS/JS**，无框架依赖，兼容性好
2. **响应式设计**，支持移动端展示
3. **LocalStorage本地存储**，用户数据持久化
4. **Mock数据**，后端未完成时也可体验完整流程
5. **模块化结构**，代码清晰易维护

## 使用说明

1. 直接在浏览器打开 `index.html` 即可使用
2. 建议使用Chrome、Safari等现代浏览器
3. 建议使用手机模式或手机访问，体验更佳
